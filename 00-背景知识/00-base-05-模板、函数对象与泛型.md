# 模板、函数对象与泛型

## 1. 模板实例化

~~~cpp
template<class T>
bool less_than(const T& a, const T& b) {
    return a < b;
}

auto a = less_than(1, 2);       // 实例化 less_than<int>
auto b = less_than(1.0, 2.0);   // 实例化 less_than<double>
~~~

编译器在看到调用时进行模板参数推导和实例化，生成具体类型的代码。模板实现通常放头文件，因为使用方需要看到定义；也可以使用显式实例化和 extern template 控制代码生成。

## 2. 普通函数、重载和特化

~~~cpp
template<class T>
int compare(T a, T b);

int compare(int a, int b); // 非模板重载
~~~

普通函数和模板都能匹配时，由重载决议综合匹配质量和模板特征，不能简单说“普通函数永远覆盖模板”。

函数模板不支持偏特化；需要部分匹配时，使用重载、约束或类模板偏特化。显式特化必须处于正确作用域，并在使用前声明：

~~~cpp
template<class T>
int compare(T a, T b) {
    return a > b;
}

template<>
int compare<const char*>(const char* a, const char* b) {
    return std::strcmp(a, b) > 0;
}
~~~

不要把 ELF 工具中的 WEAK 写成模板的语言属性；那是工具链跨翻译单元合并实例的实现策略。

## 3. 非类型模板参数

~~~cpp
template<class T, std::size_t N>
constexpr std::size_t array_size(const T (&)[N]) {
    return N;
}

int values[8];
static_assert(array_size(values) == 8);
~~~

非类型模板参数必须满足对应语言标准的常量和结构化类型要求。C++20 以后支持的类型比旧标准更多，不能再用“只有整数、指针、引用和 double”概括全部规则。

## 4. 函数对象和 lambda

~~~cpp
template<class Compare>
bool compare_values(int a, int b, Compare comp) {
    return comp(a, b);
}

auto less = [](int a, int b) { return a < b; };
compare_values(1, 2, less);
~~~

函数对象和 lambda 的具体类型在编译期已知，通常按值传递，编译器有机会内联。函数指针是运行时地址，通常需要间接调用，可能阻碍内联；但若优化器或 LTO 能证明目标唯一，也可能继续优化。

std::function 提供类型擦除和统一接口，代价可能包括间接调用、对象存储和分配。热路径应根据测量决定使用模板参数、函数对象、函数指针还是 std::function。

## 5. 编译器视角

模板和 lambda 的优势是：调用点知道具体类型，编译器能检查表达式，泛型函数可能被实例化为专用版本，具体类型让内联和常量传播成为可能。

代价是代码膨胀、编译时间增加、头文件依赖扩大以及跨动态库边界时的 ABI 管理复杂度。
