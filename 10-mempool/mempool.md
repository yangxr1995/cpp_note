定位new

- Placement New（定位new）
  - 在已分配的内存上构造对象，不分配新内存。常用于内存池或特定地址初始化。
```cpp
char buffer[sizeof(A)];
A* pa = new (buffer) A(3);  // 在buffer上构造对象
```

# SGI STL 空间配置器学习
## SGI STL 介绍
SGI STL 是由 Silicon Graphics, Inc.（SGI）公司开发的 STL 实现版本 ，是早期最具影响力的 STL 实现之一，也是许多主流 C++ 编译器（如 GCC）的 STL 底层实现（GCC 的 libstdc++ 早期基于 SGI STL 发展而来）。

核心特点
- 内存管理优化：
  - SGI STL 的分配器（std::allocator）采用了内存池技术，减少了频繁内存分配 / 释放的开销，尤其对小型对象的管理效率较高。
- 容器实现细节：
  - vector 采用连续内存存储，扩容时通常以 2 倍大小增长（不同版本可能有差异）。
  - list 是双向循环链表，支持常数时间的插入和删除。
  - map 和 set 基于红黑树（一种自平衡二叉搜索树）实现，保证了插入、查找、删除的对数时间复杂度。
- 算法效率：
  - 如 sort 算法在数据量较小时采用插入排序，数据量大时采用快速排序，最坏情况下退化到堆排序，兼顾了平均效率和稳定性。
